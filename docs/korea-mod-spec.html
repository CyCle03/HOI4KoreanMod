태그 설계

이 설계서의 핵심 결정

Project Korea의 태그 분리와 총독부 직접 플레이를 합친다. 두 태그를 쓰고, 촉발 이벤트에서 갈아탄다.

CHO · 조선총독부

시작 태그 · 일본의 통합 괴뢰국

  • 한반도 전 주를 소유하고 핵심주로 보유
  • 일본은 반도에 핵심주를 갖지 않는다
  • 자율도 최하 — 통합 괴뢰국
  • 내선일체 계열이 이 태그의 진행 방향
  • 국호 표기는 “조선”, 이념 수치 없음

KOR · 조선 / 대한민국

전환 태그 · 저항 4계열

  • 촉발 이벤트에서 저항을 택하면 태그 교체
  • 바닐라 KOR의 정당·지도자를 그대로 사용
  • 이념에 따라 국호가 넷으로 갈림
  • 임정 · 독립동맹 · 이왕가 · 인민공화국이 여기서 열림

일본 보정

밸런스 처리

  • 통합 괴뢰국은 인력·공장 지분이 종주국으로 흐른다
  • 그 비율을 맞추면 시작 국력 체감이 크지 않다
  • 부족분은 일본에 시작 modifier로 보전
  • 만주국이 이미 같은 구조라 전례가 있다

핵심주를 옮기는 이유

항복 게이지 문제

  • 바닐라에서 반도는 일본의 핵심주다
  • 그대로 두면 조선 독립이 일본 항복에 직결된다
  • 게임 초반에 일본이 즉사하면 판이 성립하지 않는다
  • 핵심주를 CHO로 옮기면 이 연쇄가 끊긴다

부작용이 하나 있다. 반도가 일본 핵심주가 아니게 되면 일본이 조선 인력을 직접 못 쓴다. 이건 autonomy_integrated_puppet의 인력 지분으로 대체하고, 내선일체 계열의 육군특별지원병령·징병제 실시가 그 지분을 올리는 중점이 되게 묶는다. 결과적으로 플레이어가 충성할수록 일본이 강해지는 구조가 되어 서사와도 맞는다.

소요일이 운 좋게 맞아떨어진다. HOI4의 cost는 1당 7일이라 설계서의 값이 정수로 떨어진다.

분기 문법도 설계 단계에서 이미 맞춰뒀다. 배타선은 mutually_exclusive, Y자 갈라짐은 한 prerequisite 블록 안의 복수 항목(OR), 합류는 prerequisite 블록을 여러 개 나열(AND), 은닉 분기와 조건부 해금은 allow_branch다. 조건이 거짓이면 트리에 아예 표시되지 않는다.

focus = {
    id = CHO_naisen_ittai
    icon = GFX_goal_generic_political_pressure
    x = 1  y = 3
    cost = 5
    # 촉발 이벤트에서 총독부 편을 들었을 때만 이 계열이 보인다
    allow_branch = { has_country_flag = KOR_loyalist_path }
    prerequisite = { focus = KOR_underground_network }
    mutually_exclusive = { focus = KOR_kpg_unify focus = KOR_yi_house focus = KOR_pr_committee }
    completion_reward = {
        add_stability = 0.10
        add_political_power = 50
        add_dynamic_modifier = { modifier = CHO_mobilization }
    }
    ai_will_do = { factor = 10 }
}

합류 지점은 블록을 나눈다. 사관학교 설립이 제도군과 유격 양쪽을 요구하는 것이 이 문법이다.

focus = {
    id = KOR_military_academy
    # 블록이 둘이면 AND — 두 조건을 모두 만족해야 한다
    prerequisite = { focus = KOR_regular_army_1 focus = KOR_regular_army_2 }
    prerequisite = { focus = KOR_guerrilla_1 focus = KOR_guerrilla_2 }
    available = { is_subject = no }
    ...
}

관문과 변수

“아홉 중 다섯”

개수 조건은 prerequisite로 표현할 수 없다. 산업 1티어 아홉 개는 서로 선행이 없으므로, 완료 수를 변수로 세고 관문에서 검사한다.

# 1티어 각 중점의 completion_reward에 공통으로
add_to_variable = { KOR_ind_tier1 = 1 }

# 관문 중점
focus = {
    id = KOR_regional_specialization
    available = {
        custom_trigger_tooltip = {
            tooltip = KOR_ind_gate_tt
            check_variable = { KOR_ind_tier1 > 4 }
        }
    }
    ...
}

최종 관문 세계 속의 조선은 1·2티어를 합산한다. 위에 13개가 있고 조건이 9이므로 넷은 건너뛸 수 있다. 툴팁에 현재 수치를 노출해야 플레이어가 몇 개 더 필요한지 알 수 있으니 custom_trigger_tooltip은 필수다.

게임 규칙

고증과 재미를 플레이어에게 넘기기

Hearts of Korea가 쓰는 방법이다. 고증 대 재미 논쟁을 설계자가 결정하지 않고 시작 화면에서 고르게 한다.

고증

KOR_difficulty = historical

  • 공장 유출 50%, 장교단 페널티 최대
  • 승인 게이지 상한 60 고정
  • 광복군 사단 정원 60%
  • 기본값. 종전까지 살아남는 것이 목표

균형

KOR_difficulty = balanced

  • 유출 35%, 페널티 절반
  • 상한 해제 조건 완화
  • 시작 민수공장 +3
  • 동유럽 마이너 수준

강화

KOR_difficulty = empowered

  • 유출 없음, 장교단 페널티 없음
  • 시작 사단 12개 · 공장 대폭 증가
  • 폴란드급 중견국
  • 멀티 또는 첫 플레이용

난이도별로 중점 트리를 바꾸지는 않는다. 바뀌는 것은 시작 국민정신의 수치와 초기 자산뿐이다. 그래야 트리 하나로 세 난이도를 모두 감당할 수 있다.

작업 순서

돌아가는 것부터
  1. 해방국 전용으로 먼저 띄운다

    일본과 주 설정은 손대지 않고, 바닐라 KOR에 저항 4계열 + 산업 + 군사만 붙인다. 콘솔로 조선을 해방시켜 트리가 뜨는지부터 확인한다. 여기까지가 하루치 작업이다.

  2. 아이콘은 전부 재활용

    GFX_goal_generic_*로 107개를 채운다. 고유 아이콘 제작은 마지막이다. 아이콘 없이도 트리는 돈다.

  3. 관문 변수와 코스메틱 태그

    산업 티어가 실제로 잠기는지, 계열마다 장비 이름이 바뀌는지 확인한다. 이 둘이 이 설계의 특징이므로 먼저 검증한다.

  4. 결정과 이벤트

    일장기 말소·카이로 선언 두 이벤트, 청구·비적 토벌 반복 결정, 종전 처리 7종. 승인 게이지 변수도 여기서 붙는다.

  5. CHO 태그와 주 재지정

    여기서 처음으로 일본을 건드린다. 반도 주의 소유·핵심을 CHO로 옮기고 통합 괴뢰국으로 묶은 뒤, 1936–41년을 관전 모드로 돌려 일본의 중일전쟁 진행이 무너지지 않는지 본다.

  6. 일본 보정과 게임 규칙

    일본 시작 국력을 맞추고, 난이도 3택을 붙인다. 여기까지 오면 사실상 완성이다.

  7. 로컬라이제이션과 아이콘

    한국어·영어 두 벌. 중점 설명문은 설계서의 효과 문구를 그대로 옮기면 된다.

가장 큰 위험

  • 반도를 종속국으로 떼면 일본의 중일전쟁 수행이 흔들릴 수 있다

  • 안 되면 5단계를 포기하고 해방국 전용으로 되돌린다
